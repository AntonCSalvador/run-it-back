# Reviewed portrait sources: 2021 cohort

Reviewed 2026-09-10. This records source research, not a production portrait import. Exact description pages, media URLs, credits, owners and crop focus are in `src/data/champions/portrait-overrides.json`.

## Review method and reuse evidence

Canonical handles and common aliases were searched on Riot Games, VALORANT Esports and PlayVALORANT before fallback research. Standalone stills were preferred; unlabelled team pictures were not assigned identities by facial recognition. Every selected image was downloaded and visually inspected for framing; identification comes from explicit source captions, Commons `featured` metadata or broadcast name labels. Search thumbnails, VLR images, fair use, unknown owners and permissions limited to Liquipedia were rejected.

For Liquipedia rows, the Commons `FileInfo` copyright identifies Riot Games. The original Riot account and its caption were reviewed separately. The reuse basis is Riot's [noncommercial fan policy](https://www.riotgames.com/en/legal), **not a transfer of Liquipedia's permission**. Photographer credits are retained when provided. Account-level credits are used where no photographer was supplied.

The [Commons Copyrights Repository](https://liquipedia.net/commons/Copyrights_Repository), retrieved through the Commons revision API, explicitly identifies Riot-owned global, EMEA, Pacific and Brazil accounts, including Brazil `191250687@N03` and Korea `145885012@N07`. Together with each file's retained-Riot-rights notice and original account metadata, this supports the exact-account **reviewed-origin** allowlist: `valorantesports`, `vctemea`, `vctpacific`, `valesportsbr`, `191250687@N03`, `145885012@N07`. `isApprovedReviewedRiotPortraitOriginalUrl` is used only by override parsing and catalog validation. Automatic `assessPortrait` retains the separate `isApprovedRiotPortraitOriginalUrl` policy: global `valorantesports` Flickr or the original exact Riot Games hosts, not regional accounts. Regression tests prove each regional candidate is rejected automatically while its explicitly reviewed override is accepted. No arbitrary Flickr accounts or lookalike suffixes are accepted.

For k1Ng, the actual `riot` branch of [Template:FileInfo](https://liquipedia.net/commons/Template:FileInfo), retrieved through the revision API, states Riot copyright and non-profit use under Riot's legal statement. The row preserves the original `riot` marker; it does not relabel it as `permission`. The reviewed-override validator still requires Riot ownership, an approved original and Riot copyright credit. Automatic license assessment is not broadened to the `riot` marker.

## Verification record

The 2021 cohort test was first run against the empty production override manifest and failed listing all 28 expected handles. Regional-account acceptance tests and the reviewed `riot` marker test were observed failing before their narrow implementation changes. All 22 selected still URLs passed `loadRemotePortrait` (15 MiB limit) and `convertPortrait` (80 MP limit) into temporary buffers; none required a thumbnail downgrade. All six contained captures passed `loadPortraitCapture` and conversion, and their 256px outputs were visually inspected. Production import remains deferred.
